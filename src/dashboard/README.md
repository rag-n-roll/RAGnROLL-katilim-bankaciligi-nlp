# Katılım Bankacılığı Dashboard

Bu klasör, Katılım Bankacılığı NLP Projesi'nin frontend bölümünü içermektedir.

Dashboard arayüzü React, Next.js ve TypeScript kullanılarak geliştirilmektedir.

## Mevcut Sayfalar

- Ana Sayfa: `/`
- Karşılaştırma Sayfası: `/compare`
- Kampanyalar Sayfası: `/campaigns`
- Chatbot Sayfası: `/chatbot`

## Kullanılan Teknolojiler

- React
- Next.js
- TypeScript
- ESLint

## Projeyi Çalıştırma

Önce dashboard klasörüne geçilir:

```bash
cd src/dashboard
```

Gerekli paketler yüklenir:

```bash
npm install
```

Geliştirme sunucusu başlatılır:

```bash
npm run dev
```

Uygulama aşağıdaki adresten açılır:

```text
http://localhost:3000
```
